# 주차별 문서

한 주에 한 편의 공동 문서를 읽고 작성합니다. 먼저 [주차별 Background 읽기 지도](../background/README.md#week-map)에서 보고서가 사용하는 구조·데이터·학습 방법과 필요한 선행 개념을 확인하세요. 각 주차 상세 가이드는 본문 구성요소별로 필요한 이유, 배경 원전과 읽을 범위, 해당 보고서의 변경점을 연결합니다.

각 문서의 세 가지 체크박스는 점수를 옮겨 적는 칸이 아니라, 읽고 나서 설명하거나 직접 따라 해 볼 수 있어야 하는 Action Item입니다. 별도의 실험 점수 보고는 필수가 아닙니다. 대신 논문의 핵심 주장, 원문 위치, 주장이 성립하는 조건과 한계를 학습 질문 안에서 확인합니다. 여러 주차에 필요한 기초는 공통 배경 문서로 연결하고, 아래에는 각 주차에서 새로 답할 질문을 정리했습니다. 같은 기반 기법을 다시 사용하는 경우에는 공통 배경을 참조하고 보고서별 변경점에 집중합니다.

상세 Background의 구성요소를 익힌 뒤 아래 세 가지 학습목표를 수행합니다. 원문 전체를 읽는 데 필요한 배경은 학습목표에서 강조한 개념 밖에서도 찾아볼 수 있습니다. 이전 주차에서 배운 기법은 연결된 설명을 복습하고, 이번 보고서에서 쓰는 방식과 달라진 조건을 확인합니다.
