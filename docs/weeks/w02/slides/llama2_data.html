RQ1 · CORE CONCEPTS

fastText vs KenLM
Language ID와 Perplexity

fastText는 문서의 언어를 분류하고, KenLM은 학습된 언어모델에서 문서가 얼마나 예측하기 어려운지 계산합니다.

fastText: Language Identification
“안녕하세요” → 한국어
“Hello” → 영어
언어별로 문서를 분류
KenLM: Language Modeling
“I like apples.”
“Apples I like the.”
학습한 n-gram 분포로 Perplexity 계산
Term쉬운 설명
n-gram연속된 n개 Token의 묶음
Perplexity (PPL)문장을 예측하기 얼마나 어려운지 나타내는 숫자
오해하면 안 되는 점PPL이 낮다고 내용이 반드시 사실이거나 좋은 글인 것은 아닙니다.
근거: CCNet · Llama 2 §4.1 Table 10RQ1 · 06
두 도구가 완전히 같은 것이 아닙니다. fastText는 영어냐 한국어냐를 분류하고, KenLM은 Wikipedia 등으로 학습한 통계적 언어모델을 통해 PPL을 계산합니다. PPL은 참과 거짓을 판정하지 않는다는 점이 중요합니다.
RQ1 · HOW IT WORKS

fastText와 KenLM은
어떻게 동작할까?

같은 문서라도 fastText는 문자 패턴으로 언어를 식별하고, KenLM은 앞선 토큰들의 확률로 Perplexity를 계산합니다.

fastText · Language Identification
언어 식별
입력 예: The cat is on the mat.
1 Character n-gram 추출
문자 조각을 특징으로 사용: cat → ca / at / cat
2 Embedding 집계
문자 조각을 벡터로 바꿔 하나의 문서 표현으로 결합
3 Hierarchical Softmax
학습된 분류기로 언어별 점수 산출: en, ko, fr…
4 Threshold 적용
최고 언어 점수 > 0.5 → 해당 언어 그룹으로 분류
KenLM · 5-gram Language Model
문서 품질 지표
사전 준비: Wikipedia로 Tokenizer와 KenLM 학습
1 SentencePiece Tokenization
문서를 Subword 토큰 시퀀스로 분해
2 5-gram 확률 계산
이전 최대 4개 토큰으로 다음 토큰 예측
P(mat | cat, is, on, the) (단어 단위 도식)
3 Kneser–Ney Smoothing
드문 토큰 조합도 낮은 차수 통계를 이용해 확률 추정
4 Perplexity → 품질 구간
토큰별 확률을 종합해 PPL 계산 → Head / Middle / Tail
예시 해석“The cat is on the mat.”과 “Mat the on is cat the.”는 모두 영어로 식별될 수 있지만, KenLM의 PPL은 다를 수 있습니다. 실제 측정 결과는 아니며, Llama 2의 KenLM 사용은 공개되지 않았습니다.
근거: CCNet §3.3–3.4 · LLaMA 1 §2.1 (처리 과정 예시)RQ1 · 07
fastText는 단순히 언어 이름을 바로 출력하는 것이 아니라 문자 n-gram을 특징으로 추출하고, 이를 벡터로 결합한 뒤 hierarchical softmax 분류를 수행합니다. CCNet에서는 최대 언어 점수가 0.5보다 높을 때 언어를 확정했습니다. KenLM은 별도로 Wikipedia 데이터로 학습된 SentencePiece 토크나이저와 5-gram Kneser–Ney 언어모델을 사용합니다. 문장을 Subword로 쪼개고 이전 최대 네 토큰을 바탕으로 각 토큰의 확률을 계산합니다. 드문 조합에서는 Kneser–Ney smoothing으로 확률을 추정합니다. 마지막으로 이 확률을 합쳐 Perplexity를 계산하고 Head, Middle, Tail 그룹으로 분류합니다. 영어 문장이라고 해도 단어 배열이 이상하면 PPL이 높을 수 있습니다. 숫자들은 실제 측정하지 않았고 원리 설명을 위한 예시입니다. Llama 2가 KenLM을 사용했는지는 원논문으로 확인할 수 없습니다.

Pairwise Preference는 하나의 Prompt에 대한 두 Response를 사람이 비교해 더 나은 답을 고르는 방식입니다.

Prompt

Response A
“태양의 중력 때문에 궤도를 돕니다.”
Chosen: 사람이 선택
Response B
“지구가 태양을 밀어서 움직입니다.”
Rejected: 선택되지 않음
1 Pairwise ComparisonPrompt 1개 + Response A/B + 더 좋은 답을 고른 기록 = 비교 데이터 한 건
