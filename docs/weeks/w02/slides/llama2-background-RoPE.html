RNN 앞 토큰의 상태를 다음 토큰에 전달 → 순서가 연산 경로에 들어감Self-attention 토큰 사이 관계를 직접 비교 → 위치 정보는 별도로 반영

원리 설명토큰 임베딩은 내용을 표현하고, 위치 인코딩은 각 토큰의 자리와 토큰 사이의 간격을 반영합니다.

영어 문장과 한국어 뜻을 함께 표시한 설명용 예시입니다. dog / bites / man은 단어 단위로 나눴으며 실제 토크나이저 결과가 아닙니다.
