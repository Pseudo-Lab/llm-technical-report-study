# W00 — OT

프로젝트의 시작 배경, 학습 목표와 운영 방식, 팀원 소개를 담은 17장 HTML 발표자료입니다.

## 발표자료

- [OT 발표자료 HTML](index.html)
- [HTML 다운로드](https://github.com/Pseudo-Lab/llm-technical-report-study/raw/refs/heads/main/docs/weeks/w00/index.html)

HTML 파일을 다운로드한 뒤 브라우저에서 열면 됩니다. 이미지와 스타일이 파일에 포함돼 있어 별도 설치 없이 실행됩니다. GitHub의 파일 화면에서는 HTML 소스가 표시됩니다.

## 조작

- `←` / `→`: 이전·다음 슬라이드
- `O`: 전체 목차
- `F`: 전체 화면
- `Home` / `End`: 첫·마지막 슬라이드
