# v2 스킬 검증 결과 (2026-11-01)

> 저장소에는 보고서(`comparison.md` · `verify-criteria.md` · `verification.md`)만 올렸다. 본문에 나오는 `baseline-v1/` · `baseline-v2/` · `teammate/` · `shots/` 경로는 작업 파일이라 올리지 않았다(팀원 덱 원본은 `../slides/qwen-architecture-deck.html`).

v2 스킬로 같은 범위(W03 Architecture & Pre-training)를 다시 만든 덱 `baseline-v2/arch-deck.html`을 [미리 정한 합격 기준](verify-criteria.md)으로 판정했다. 비교 대상은 v1 덱(`baseline-v1/`)과 팀원 덱(`teammate/`)이다.

**결론: 11개 기준 중 9개 통과, 1개 부분 통과, 1개 미달**이다. 장당 글은 v1의 절반으로 줄었고(680 → 357자), 주제별 대결에서도 v1보다 나아졌다. 미달 하나는 수치 감사(틀림 · 표시 없는 계산 7건)다.

**결정(2026-11-01):** 발표자 판단으로 이번 개정은 이 상태로 확정했다. 퀴즈 기준(원래 10번, v2 미달)도 같은 판단으로 뺐다. 미달 하나는 다음 개정 후보로 남긴다.
- 근거 패널 글도 수치 감사 대상에 넣는다.

v2 덱은 실험용이라 저장소에 올리지 않았고, 감사 7건도 고치지 않았다.

## 측정 방법

- **화면 지표:** `deck_metrics.cjs`(v1 · 팀원 덱과 같은 도구)와 `check_deck.cjs`(1440×900 · 860×760 · 390×844).
- **주제 · 수치:** 비교 Workflow(에이전트 60개).
  - 주제 지도와 범위 점검
  - 수치 감사 3구간 → 지적마다 반박자 2명
  - 주제별 대결 13개 → v2가 지거나 비긴 주제는 읽는 순서를 바꿔 재판정
- **판정 기준:** 앞 회차(v1 대 팀원)와 같은 판정 기준을 썼다.
